# RWKTV — Android / Android TV

مشروع أولي وظيفي لمشغّل IPTV بواجهة عربية RTL، باستخدام Kotlin وAndroidX Media3 (ExoPlayer).

## الميزات الحالية
- استيراد ملفات محلياً عبر منتقي ملفات Android، دون طلب صلاحية تخزين شاملة.
- قراءة M3U وM3U8 نصياً وTXT.
- صيغ TXT المدعومة: رابط واحد في كل سطر، أو `اسم القناة|الرابط`، أو `اسم القناة,الرابط`.
- تشغيل روابط HTTP/HTTPS وRTSP المتوافقة مع Media3.
- البحث، والمفضلة داخل الجلسة الحالية، ورسائل خطأ بدلاً من إنهاء التطبيق في حالات الإدخال المتوقعة.
- عناصر قابلة للتركيز باستخدام الريموت، وفئة تشغيل Android TV.
- سقف حماية لحجم الملف 15MB وعدد القنوات 10,000، وعرض 5,000 قناة كحد أقصى في القائمة.

## المتطلبات
- Android Studio حديث يدعم Android Gradle Plugin 8.7.3.
- JDK 17.
- Android SDK Platform 35.
- اتصال إنترنت لتنزيل Gradle dependencies عند أول بناء.

## التشغيل
1. فك ضغط `RWKTV-project.zip`.
2. افتح مجلد `RWKTV` في Android Studio.
3. وافق على Gradle Sync وتنزيل المتطلبات.
4. شغّل التطبيق على محاكي أو جهاز Android.
5. لإنتاج APK: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. مكان APK المعتاد: `app/build/outputs/apk/debug/app-debug.apk`.

## تنسيق قائمة M3U
```m3u
#EXTM3U
#EXTINF:-1 group-title="أخبار",قناة تجريبية
https://example.com/live.m3u8
```

## تنسيق TXT
```text
قناة تجريبية|https://example.com/live.m3u8
https://example.com/another-stream.m3u8
```

## ملاحظات مهمة
- هذا **مشروع مصدر** وليس APK مبنياً؛ لم يُنفّذ بناء Gradle أو اختبار على أجهزة حقيقية في بيئة الإنشاء هذه.
- لا يمكن ضمان انعدام الأعطال دون اختبارات على أجهزة فعلية وملفات وروابط مختلفة.
- توافق البث يعتمد على نوع الترميز والحاوية والخادم. روابط HLS غالباً مناسبة؛ بعض صيغ MPEG-TS أو RTSP قد تتطلب إعدادات إضافية.
- القوائم التي تستخدم روابط HTTP غير المشفرة محجوبة افتراضياً في Android الحديثة. لا تفعّل cleartext بشكل عام؛ الأفضل استخدام HTTPS.
- أسماء القنوات وروابط البث لا تُرسل إلى أي خادم بواسطة هذا التطبيق.
- استخدم قوائم وروابط لديك حق الوصول إليها.
- هذا إصدار تأسيسي؛ المفضلة غير محفوظة بعد إغلاق التطبيق، ولا توجد إدارة EPG أو تسجيل دخول/اشتراكات.
